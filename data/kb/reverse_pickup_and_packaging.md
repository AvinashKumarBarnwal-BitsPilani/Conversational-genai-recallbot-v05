ShopSphere Reverse Pickup and Packaging Guide
Document ID: KB-013 | Version: 1.3 | Effective: 2026-01-01 | Status: active

Pickup eligibility
A reverse pickup can be scheduled after a return or exchange is authorised. The selected date must be available in the pickup service and, under the current standard flow, must fall within seven calendar days after authorisation. The return request must identify the correct order and item. A pickup booking is not proof that the carrier collected the parcel. The carrier scan is required to move the return to the collected state.

Scheduling windows
Pickup services may offer morning, afternoon and evening windows depending on the postal code and carrier capacity. An evening slot is not guaranteed merely because the customer has a saved delivery preference. The scheduler must return an available slot for the actual return address. If a requested slot is full, show the nearest alternatives and ask the customer to choose. Never silently substitute a different date or time window.

Customer confirmation
Before creating a pickup, show the order ID, item description, return reason, pickup date, time window and address summary. The customer must confirm that summary. The write operation should include the confirmation source and timestamp. If the customer changes a date or time after confirming, present a new summary and obtain confirmation again. “Proceed” may count as confirmation only when the immediately preceding assistant message clearly showed the complete action summary.

Packaging
Use a strong outer carton or approved return pouch. Protect fragile items with sufficient cushioning and prevent loose accessories from moving inside the package. Include only the items listed in the return authorisation. Remove or cover old shipping labels so the carrier scans the correct return label. Do not include batteries or hazardous materials unless the carrier instructions explicitly permit them.

Missed pickup
If the carrier misses the scheduled pickup, first check the carrier event. If no attempt was recorded, create a reschedule request using the next available slot. If the carrier records an unsuccessful attempt, explain the scan and ask whether the customer wants another available slot. Do not create a second RMA for the same item. Keep the existing RMA identifier and add a pickup reschedule event.

Handover evidence
At collection, the carrier should scan the return label and provide a pickup receipt or digital confirmation. The customer should retain the receipt until the return is accepted or the refund is initiated. If the carrier takes the parcel without a scan, escalate with the pickup reference and timestamp.

ShopSphere Gift Cards and Promotion Rules
Document ID: KB-015 | Version: 1.2 | Effective: 2026-01-01 | Status: active

Gift cards
A ShopSphere gift card is a prepaid stored-value instrument that can be redeemed at checkout for eligible products. The gift card code should be entered only in the official ShopSphere checkout. Support agents must never ask a customer to share a complete unused gift card code in a public chat. A partially masked reference is sufficient for most investigations. Gift cards are not eligible for ordinary change-of-mind returns once delivered, although a proven activation or balance error can be investigated.

Discount codes
A promotion code may be restricted by start date, expiry date, product category, seller, minimum basket amount or membership tier. A code that is expired or excluded by the promotion terms should not be promised as valid. The checkout service calculates the final discount and is authoritative when multiple offers are present. The assistant may explain why a code failed when the response includes a reason, but must not invent an alternative code.

Stacking and refunds
Unless the offer explicitly permits stacking, only one promotional code can be applied to a basket. When a discounted item is returned, the refund service calculates the item-level amount after allocating the discount. The customer should receive the amount returned by the refund service, not a manual calculation based on the undiscounted catalogue price. Shipping promotions may be reversed if the remaining basket no longer meets the offer conditions.

Examples of internal references
PROMO-GOLD-SHIP is an illustrative identifier for the Gold standard-shipping promotion. GFT-ACT-01 identifies a gift-card activation investigation. DISC-EXP-02 identifies an expired promotion code response. These references help support teams classify an issue; they are not customer redemption codes. A customer-facing response should not imply that an internal reference can be entered at checkout.

Fraud prevention
If a customer reports a message asking them to buy gift cards and send photographs or codes, treat it as a potential scam. Advise them not to share the code and route the report to ACCOUNT-SECURITY. ShopSphere will not request gift card codes to release a parcel, approve a refund or verify an account.
